# SEO Rules Reference — правила SEO Wildberries 2026

Справочник всех актуальных правил SEO WB на 2026 год. Используется как основа для системного промпта и для ревью при обновлении.

**Важно:** этот документ не загружается в промпт LLM — он слишком большой и нужен людям (оператору, ревьюеру промпта). В `system_prompt.md` попадают только сжатые правила, извлечённые отсюда.

---

## 1. Что индексируется поиском WB

Поисковый алгоритм WB индексирует текстовые ключи только в четырёх полях карточки:

1. **Название** (Title) — наибольший вес в ранжировании по текстовой релевантности
2. **Характеристики** — включая обязательные фильтруемые и опциональные дополнительные
3. **Описание** — до 5000 символов
4. **Бренд** — отдельное поле

**НЕ индексируются:**
- Комплектация
- Отзывы
- Вопросы-ответы
- Примечания
- Инфографика (текст на картинках)

Вписывать ключи в неиндексируемые поля — потеря места и усилий.

---

## 2. Алгоритм ранжирования 2026 (веса)

Официально WB не раскрывает формулу, но по совокупности данных:

| Фактор | Вес | Комментарий |
|--------|-----|-------------|
| Скорость доставки (FBO-логистика) | 30–40% | Самый сильный фактор |
| Реклама (Бустер, кампании тип 9) | 15–25% | Второй по силе |
| Конверсия (CTR, корзина, заказы) | 5–20% | Растущая значимость |
| Текстовая релевантность + заполненность | до 10% | Основной SEO-фактор |
| Рейтинг товара/продавца | ~10% | Падение ниже 4,5 режет трафик |
| Индекс цен (сравнение с Ozon/Lamoda) | до 10% | «Выгодно» = +10% |
| Программа лояльности продавца | 1–2% | Бронза/серебро/золото |
| Участие в акциях | 1–10% | |

**Вывод для SEO:** чисто текстовая оптимизация даёт до 10% веса, но без неё остальные факторы тоже срабатывают хуже (нельзя попасть в выдачу по запросу, если запрос не проиндексирован в карточке).

## 3. Поисковые кластеры (критически важно)

WB сам группирует близкие запросы в кластеры. Кластер = группа запросов, дающих одинаковую поисковую выдачу.

**Примеры кластеров:**
- «носки мужские» + «мужские носки» + «носки для мужчин» — один кластер
- «носки мужские набор» — уже отдельный кластер (добавилось значимое слово)
- «свеча ароматическая» + «ароматическая свеча» — один кластер

### Следствия для SEO

1. **Не прописывать все вариации** одного кластера — одна форма подтянет остальные автоматически
2. **Прописывать смежные кластеры**, отличающиеся значимым словом — каждый новый кластер открывает новую воронку трафика
3. **Признаки объединения в кластер:** словоформы (род, число, падеж), порядок слов, очевидные синонимы
4. **Признаки разделения:** добавление размера, материала, назначения, количества

### Изменение февраля 2026

Завершилась миграция рекламных кампаний с типа 8 на тип 9. Ключевое: теперь у каждого артикула собственные поисковые кластеры (раньше были общими для всех товаров в кампании). Это означает, что качество SEO на уровне отдельной карточки стало ещё важнее.

## 4. Правила для названия

### Формат
- Максимум 60 символов
- Связное словосочетание, не перечисление через запятую
- Главный ВЧ-ключ в первые 1–3 слова

### Структура
- 1 прямое вхождение главного запроса
- 1–2 уточняющих атрибута: материал, назначение, фасон, размер

### Запрещённые символы
- Слэш `/` — WB воспринимает как разделитель товаров
- Эмодзи любые (🔥 ⭐ 💎)
- Спецсимволы ★ ♥ ✓ ❤
- Восклицательные знаки (можно в описании, но не в названии)
- CAPS для привлечения внимания
- Повторяющиеся пробелы

### Запрещённые слова
- «купить», «цена», «стоимость» — не для внутренней выдачи WB
- «скидка», «распродажа», «акция» — используй встроенные механики, а не текст
- Оценочные: «лучший», «идеальный», «элегантный», «премиальный», «уникальный», «шикарный»
- Бренд в названии — только если действительно в поле «Бренд» не попало, иначе дубль

### Пример
- ✅ «Рюкзак женский городской для ноутбука 14 нейлон»
- ❌ «🔥СТИЛЬНЫЙ женский рюкзак/сумка из натуральной кожи купить недорого!!!»

## 5. Правила для характеристик

### Общие принципы
- Заполнять ВСЕ доступные поля (не только обязательные)
- Минимум 8 заполненных полей на карточку
- В фильтруемых полях — значения строго из выпадающих списков WB
- В текстовых полях — по назначению поля (в «Составе» — реальный состав, не ключи)

### Распределение семантики
- **ВЧ** — только в названии, в характеристиках они часто и так задаются фильтрами
- **СЧ** — в основных текстовых характеристиках
- **НЧ** — в описательных полях
- **Околотематика** — в дополнительных полях: «Назначение», «Особенности модели», «Для кого», «Повод», «Тип»

### «Скрытое SEO» в доп. полях
Дополнительные поля позволяют вписывать 3–5 слов, которые индексируются поисковиком, но не дублируют основной текст описания. Идеально для низкочастотных и околотематических запросов, за которые невозможно получить бан.

### Примеры доп. полей по категориям
- Одежда: «Повод», «Сезон», «Стиль», «Особенности модели»
- Электроника: «Совместимость», «Тип подключения», «Комплектация» (для фильтров)
- Детские товары: «Возраст», «Пол ребёнка», «Материал»
- Товары для дома: «Назначение», «Для комнаты», «Стиль интерьера»

## 6. Правила для описания

### Формат
- Максимум 5000 символов с пробелами
- Абзацы разделены одной пустой строкой
- Без markdown-разметки (WB её не поддерживает, отобразится как есть)

### Семантика в описании
- Преобладают **непрямые вхождения** — слова запроса разделены другими словами
- Прямые вхождения — только 1–2 раза в самых значимых местах
- Каждый ключ **≤ 3 раз во всей карточке суммарно** (название + характеристики + описание)
- Главный ВЧ-ключ в описании **≤ 2 раз** (он уже в названии)

### Рабочая структура (6 блоков)
1. Крючок (2–3 строки): кто покупатель и когда ему это нужно
2. Свойства через выгоды (4–6 строк)
3. Технические подробности (3–5 строк)
4. Комплектация + что НЕ входит (2–3 строки)
5. Сценарии и поводы (3–5 строк)
6. Бренд/финал (1–2 строки)

### Запрещено
- Копирование описаний конкурентов — алгоритм отслеживает дубли
- «Вода» без конкретики («высокое качество», «долговечный», «удобный»)
- Обращения «Дорогой покупатель!», «Уважаемые клиенты!»
- Больше одного восклицательного знака на всё описание
- Сравнения с конкретными конкурентами

## 7. Переспам и санкции

### Что алгоритм считает переспамом

1. Повтор одного слова более 3 раз в рамках всей карточки
2. Перечисление ключей через запятую внутри одного поля
3. Близкие вариации одного слова (мужской/мужская/мужские/мужское подряд)
4. Словоформы одного запроса («рюкзак школьный, рюкзак для школы, школьный рюкзак»)
5. Нерелевантные ключи под высокочастотный охват
6. Вписывание чужих брендов
7. Дубли слов между разными полями (кроме обязательных значений фильтров)

### Последствия переспама (по двум сценариям)

**Сценарий 1 — явный спам-фильтр:**
Ключевые запросы присутствуют в карточке, но показов по ним нет. Ранжирование по запросу резко падает. Избавление от переспама восстанавливает позиции за 1–2 недели.

**Сценарий 2 — органическая пессимизация (коварнее):**
Вес карточки накапливается, но передаётся запросам не полностью. Продажи есть, а роста позиций не происходит. Диагностика сложная, лечение — полная переоптимизация.

### Антифрод 2026

С января 2026 действует ML-система антифрода (совместно с Билайн), которая выявляет:
- Накрученные отзывы (боты, одна IP-подсеть)
- Самовыкупы
- Накрутку лайков к отзывам

Карточка с признаками манипуляций получает пессимизацию.

## 8. Сбор семантического ядра (для справки)

Порядок источников:
1. **Внутренний отчёт ЛК WB:** Аналитика → «Поисковые запросы на WB» — прямая статистика показов
2. **Семантика 10–30 топовых конкурентов** через MPStats / Sellmonitor / WeCheck — реальные ключи, дающие показы
3. **Яндекс Вордстат** — для расширения, но осторожно (много нерелевантных для маркетплейса запросов)

### Распределение по частотности (рекомендации экспертов расходятся)
- По MPStats: ВЧ 30% / СЧ 40% / НЧ 30%
- По InSales: ВЧ 30% / СЧ 50% / НЧ 20%
- Общая практика: 10–30 итоговых запросов в карточке после фильтрации

### Критерии фильтрации
- **Удалять нерелевантные** («чёрная блузка» для изумрудной блузки)
- **Удалять близкие вариации** одного кластера
- **Удалять запросы с «купить/цена/обзор»** — они для внешних поисковиков, не для WB
