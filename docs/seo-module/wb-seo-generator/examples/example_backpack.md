Особенности модели: USB-разъём для зарядки, мягкая спинка, регулируемые лямки
Назначение: повседневный, для работы, для учёбы
Для кого: для женщин
Повод: на каждый день
Страна производства: Россия

Дорога на работу: ноутбук, косметичка, зонт, контейнер с обедом. Всё умещается в одном рюкзаке, который не выглядит как офисный.

Нейлон 600D с водоотталкивающей пропиткой — капли скатываются, содержимое остаётся сухим в умеренный дождь. Основное отделение открывается широко, поэтому доставать вещи со дна не приходится. Внутри — отдельный карман с мягкой прослойкой под ноутбук до 14 дюймов, ничего не стучит о спинку при ходьбе.

Лямки широкие, с мягкой внутренней поверхностью. К концу дня плечи не устают — это то, на что часто жалуются в отзывах на похожие модели. Сзади есть USB-разъём: подключаете пауэрбанк изнутри и заряжаете телефон на ходу.

Размеры 40×28×12 см, вес 480 грамм — лёгкий даже с полной загрузкой. Объём 14 литров.

В комплекте: рюкзак и фирменный мешочек для хранения. Пауэрбанк и кабель USB не входят — их нужно взять свои.

Подойдёт тем, кто ищет городской рюкзак для офиса без спортивных деталей и без крупного логотипа. В пыльно-розовом цвете, который сочетается с большинством базового гардероба. Как подарок девушке — работает, если она ценит функциональные вещи.

Одна форма. Один материал. Ничего лишнего.

## Как использовать в тестах

### Юнит-тест парсера
```python
def test_parser_on_example():
    with open("examples/example_backpack.md") as f:
        content = f.read()
    # Извлекаем блок между ``` (expected output)
    raw_output = extract_expected_output(content)
    card = parse_llm_output(raw_output)

    assert card.title == "Рюкзак женский городской для ноутбука 14 нейлон"
    assert len(card.characteristics) == 12
    assert len(card.description_blocks()) == 6
    assert card.report.coverage == 9
```

### Интеграционный тест валидатора
```python
def test_validator_on_example():
    brief = load_brief_from_example()
    card = load_expected_output_from_example()

    report = validate(card, brief)

    assert not report.failed
    assert len(report.error_messages) == 0
```

### End-to-end тест (требует OpenRouter API key)
```python
@pytest.mark.integration
def test_generation_end_to_end():
    brief = load_brief_from_example()
    client = OpenRouterClient(model="anthropic/claude-haiku-4.5")

    card = generate_card(brief, client)
    report = validate(card, brief)

    assert not report.failed, f"Validation errors: {report.error_messages}"
    # Качественные проверки — с допусками
    assert 30 <= len(card.title) <= 60
    assert 800 <= len(card.description) <= 5000
    assert len(card.characteristics) >= 8
    assert report.coverage >= 7  # хотя бы 7 из 13 кластеров
```

## Заметки о вариативности

LLM не генерирует байт-в-байт одинаковые ответы. Поэтому e2e-тест проверяет не точное совпадение, а набор ограничений:

- Название содержит «рюкзак» и «женский» (или «городской»)
- В характеристиках заполнены обязательные фильтруемые поля (минимум: Материал, Объём, Цвет, Вес)
- Описание содержит 6 блоков
- В описании есть упоминание «не входит» (потому что `ne_vhodit` задан в брифе)
- Валидатор не возвращает errors

Эталонный выход в этом файле — один из валидных вариантов, а не единственно правильный.
