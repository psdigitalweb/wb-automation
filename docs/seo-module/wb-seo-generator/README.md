# WB SEO Generator

Сервис массовой генерации SEO-текстов карточек Wildberries на основе LLM. Принимает Excel-таблицу с брифами по SKU, возвращает Excel-таблицу со сгенерированными названиями, характеристиками и описаниями.

---

## Быстрый старт

```bash
# 1. Установить зависимости
pip install -e .

# 2. Прописать ключ OpenRouter
echo "OPENROUTER_API_KEY=sk-or-..." > .env

# 3. Подготовить брифы
cp input/briefs.example.xlsx input/briefs.xlsx
# заполнить своими SKU

# 4. Запустить
python -m wb_seo_generator run --input input/briefs.xlsx --output output/results.xlsx

# 5. Проверить результаты и отчёт
python -m wb_seo_generator report --output output/results.xlsx
```

## Как это работает

1. **Загрузка брифов.** Читаем Excel-таблицу, каждая строка → pydantic-модель `Brief`.
2. **Формирование промпта.** Системный промпт (стабильный, кэшируется в OpenRouter) + user-сообщение с конкретным брифом в YAML.
3. **Вызов LLM.** По умолчанию — Claude Haiku 4.5 через OpenRouter.
4. **Парсинг ответа.** Разрезаем по разделителям `===== SECTION =====`, получаем `GeneratedCard`.
5. **Валидация.** Прогоняем через набор проверок (см. `docs/validation_rules.md`). Если ошибки — retry с обратной связью; если retry не помог — fallback на Sonnet 4.5.
6. **Сохранение.** Результат записывается в выходной Excel построчно. При падении процесса партия продолжается с места остановки.

## Модели и стоимость

### Рекомендации

| Модель | Когда использовать |
|--------|---------------------|
| `anthropic/claude-haiku-4.5` | Основная модель — лучший баланс цены и качества на русском |
| `anthropic/claude-sonnet-4.5` | Fallback при провале валидации Haiku + для критически важных карточек |
| `deepseek/deepseek-chat` | Для прототипирования и массовой черновой генерации |
| `google/gemini-2.5-flash-lite` | Альтернатива Haiku для экономии, но хуже на русском |

### Ориентировочная стоимость партий

На базовой модели (Haiku 4.5), с prompt caching:
- 100 SKU ≈ $1,1
- 500 SKU ≈ $5,5
- 1000 SKU ≈ $11

## Обновление правил SEO

Правила WB меняются 2–4 раза в год. Чтобы обновить:

1. Проверить источники из `docs/seo_rules_reference.md` раздел 9
2. Внести изменения в `docs/seo_rules_reference.md`
3. Обновить `prompts/system_prompt.md` (он — сжатая версия референса)
4. Обновить `docs/validation_rules.md` если появились новые программные проверки
5. Прогнать интеграционный тест — если эталонный пример всё ещё проходит валидацию, изменения совместимы

## CLI

```
Usage: python -m wb_seo_generator COMMAND [OPTIONS]

Commands:
  run        Запустить генерацию на партии
  validate   Перепроверить уже сгенерированную партию (без вызова LLM)
  report     Сводная статистика по партии
  test       Сгенерировать тестовую карточку на example brief

Options для run:
  --input PATH          Путь к Excel с брифами
  --output PATH         Путь для записи результатов
  --model NAME          Модель OpenRouter (по умолчанию anthropic/claude-haiku-4.5)
  --fallback NAME       Fallback-модель (по умолчанию anthropic/claude-sonnet-4.5)
  --dry-run             Не вызывать LLM, только валидировать схемы брифов
  --skip-validation     Сохранять результаты без валидации (не рекомендуется)
  --max-budget FLOAT    Остановиться, если бюджет партии превысит N долларов
```

## Диагностика

### Частые ошибки валидации и что делать

| Ошибка | Причина | Фикс |
|--------|---------|------|
| `Название > 60 символов` | LLM пытается впихнуть все ВЧ | Убрать лишние ВЧ из брифа, оставить 2–3 |
| `Ключ 'X' встречается 5 раз` | Переспам | Убрать близкие вариации ключа из семантики |
| `Описание < 6 блоков` | Модель не следует структуре | Увеличить температуру до 0,5 или переключить на Sonnet |
| `Главный ВЧ не в первых 3 словах` | В брифе порядок ВЧ перепутан | Поставить нужный ВЧ первым в `семантика.вч` |
| `Запрос помечен как использованный, но не найден` | LLM галлюцинирует отчёт | Фикс в промпте не нужен — валидатор защищает |

### Как отлаживать один SKU

```bash
python -m wb_seo_generator test --sku WB-BACKPACK-001 --verbose
```

Покажет полный промпт, сырой ответ LLM, результаты парсинга и валидации по каждой проверке.

## Ограничения

- Сервис генерирует тексты, но не загружает их в WB. Загрузка — отдельный шаг через WB Content API или ручной импорт
- Сервис не собирает семантику сам. Семантическое ядро должно быть собрано отдельно (MPStats, Sellmonitor, внутренний отчёт ЛК WB)
- Сервис не проверяет цены и логистику — это отдельные факторы ранжирования, не относящиеся к SEO-тексту
- Качество на русском у разных моделей разное. Перед массовой генерацией протестировать 10 SKU на целевой модели
