# Ecomcore — Design System Brief v1.0

> Компактный референс для передачи в новые чаты Claude.
> Вставляй этот документ в начало каждого чата по UI ecomcore.

---

## Продукт

Ecomcore — SaaS-панель для управления продажами на маркетплейсах (Wildberries, Ozon, YM). Десктопная админка, пользователи — менеджеры e-commerce. Только светлая тема (тёмная определена в токенах, но не в приоритете).

## Визуальный характер

Тёплый нейтральный, воздушный, но плотный по данным. Не «весёлый SaaS», а рабочий инструмент с чистой типографикой. Акцент — глубокий forest green. Минимум декора, максимум полезной плотности. Стиль близок к Linear / Vercel / Notion — modern professional tool.

## Шрифт

- **Sans:** Geist (400, 500, 600, 700) — основной шрифт. В CSS: `"Geist", "Inter", ui-sans-serif, system-ui, sans-serif`
- **Mono:** Geist Mono (400, 500, 600) — для цифр, кодов, артикулов
- **Особенности:** `font-feature-settings: "cv11", "ss01", "ss03"`, tabular-nums для числовых колонок
- **Рендер:** `-webkit-font-smoothing: antialiased; text-rendering: optimizeLegibility`

## Тени

- `--shadow-xs`: минимальная — нижняя граница кнопок
- `--shadow-sm`: карточки по умолчанию
- `--shadow-md`: поповеры, дропдауны
- `--shadow-lg`: модальные окна
- `--shadow-focus`: `0 0 0 3px oklch(38% 0.10 155 / 0.22)` — кольцо фокуса

## Бордеры

Везде `0.5px solid var(--color-border)`. Тонкие, полупрозрачные.

## Layout Shell

- Сайдбар: `232px` (или `56px` collapsed), белый фон, иконки + текст
- Активный пункт сайдбара: `--color-accent` фон, белый текст
- Topbar: `52px` высота
- Subbar (табы/фильтры): `44px` высота
- Основная область: `--color-bg` фон

## Компоненты — ключевые правила

### Кнопки
- Primary: `--color-accent` фон, белый текст, `--radius-sm`, высота `--control-h`
- Secondary: белый фон, `--color-border-strong` бордер, `--shadow-xs`
- Ghost: прозрачный, hover → `--color-surface-2`
- Danger: `--color-danger` фон, белый текст
- Размеры: sm (28px), default (32px), lg (40px), icon (квадрат)

### Инпуты
- Белый фон, `0.5px solid --color-border-strong`, `--radius-sm`
- Focus: бордер `--color-info` + `--shadow-focus`
- Placeholder: `--color-text-3`

### Карточки
- Белый фон, `0.5px` бордер, `--radius-lg`, `--shadow-sm`
- Header: flex row, space-between, `border-bottom`

### Таблицы
- Обёртка: белый фон, `--radius-lg`, `0.5px` бордер
- Заголовки: `--text-xs`, uppercase, `0.04em` letter-spacing, `--color-surface-2` фон, `--color-text-3`
- Ячейки: `10px 14px` padding
- Hover строки: `--color-surface-2`
- Числа: `font-variant-numeric: tabular-nums`, выравнивание вправо

### Бейджи
- Pill shape (`--radius-pill`), высота 20px, `--text-xs`
- Варианты: default (серый), info, success, warning, danger, mp-wb

### Табы
- Нижний бордер `0.5px`, активный — `2px solid --color-text`
- Segmented: `--color-surface-2` подложка, активный — белый фон + `--shadow-xs`

### KPI-блоки (из дашборда)
- Большое число: `--text-3xl` (32px), `--weight-bold`
- Дельта: зелёная (+) или красная (−), `--text-sm`
- Подпись: `--text-sm`, `--color-text-2`

### Алерт-карточки (из «Требует внимания»)
- Flex row: MP-бейдж + точка-статус + текст + бейдж-счётчик справа
- Бордер: `0.5px`, `--radius-lg`

## Анимации

- `--ease-out: cubic-bezier(0.2, 0.8, 0.2, 1)`
- `--duration-fast: 120ms` — hover, focus
- `--duration-base: 180ms` — открытие элементов
- `--duration-slow: 280ms` — переходы страниц

## Иконки

Lucide (из скриншотов: настройки ⚙, графики 📊, сигнал 🔔, расходы 📋). Размер иконок в сайдбаре ~18-20px, в кнопках ~14-16px.
