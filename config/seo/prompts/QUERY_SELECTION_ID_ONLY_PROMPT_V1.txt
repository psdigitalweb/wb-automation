Ты помогаешь выбрать поисковые запросы для карточки товара на маркетплейсе.

Задача:
Из списка query candidates выбери запросы, которые реально подходят этому товару по смыслу, визуальному образу и покупательскому намерению.

Товар:
Тип товара: {product_type}

Название:
{title}

Описание:
{description}

{category_style_hint}

{vision_evidence}

Правила выбора:
- Покупательские смыслы товара важнее частотности.
- Частотность помогает выбирать между одинаково релевантными запросами, но не делает нерелевантный запрос подходящим.
- Более низкочастотный, но точный запрос лучше высокочастотного, который совпадает только по общей категории.
- Сначала выдели смысловые линии товара из названия, описания, фото и покупательских признаков.
- Для каждой линии выбери подходящие id отдельно.
- Нишевая смысловая линия не должна исчезать только потому, что ее запросы менее частотные, чем общие запросы категории.
- Частотность используй только для выбора между запросами внутри одной и той же смысловой линии.
- Если в товаре явно есть визуальный или эмоциональный стиль, обязательно проверь кандидаты этой линии и выбери подходящие id даже при меньшей частотности.
- selected: ориентир 30-50 запросов всего, если в candidates есть достаточно релевантных.
- operator_candidates: ориентир 10-20 спорных или пограничных запросов всего.
- Лучше вернуть 18 хороших запросов, чем 50 с мусором.
- Не сокращай ответ до 5-10 запросов, если есть больше смыслово подходящих вариантов.
- Выбирай только запросы, которые действительно подходят товару.
- Если запрос содержит конкретный атрибут, которого нет в товаре, не выбирай его.
- Не выбирай общий запрос только потому, что он частотный, если есть более точные запросы по этому товару.
- Если запрос подходит по стилю/аудитории, но не идеально доказан, добавь его в operator_candidates.
- Не возвращай rejected: всё, что не выбрано, считается отклонённым.
- Внутри selected/operator_candidates верни только id из таблицы query candidates.
- Не возвращай тексты запросов, reasons или confidence.

Верни JSON строго в формате:
